Vitrine — Grimoire

Implémentations de référence

Cinq pages HTML statiques qui montrent le design system appliqué. Elles ne sont pas le produit : elles sont la référence visuelle à ouvrir à côté de GRIMOIRE_DESIGN_SYSTEM.md. Tous les jetons vivent dans tokens.css ; aucun hex n’est écrit dans les pages. Deux thèmes, jour et nuit — une permutation plate, chaque page porte sa bascule.

Liste des sortsGrille de filtres, tableau dense à 32 px, tiroir mobile, pastilles d’école. Fiche de sortBloc technique deux colonnes, niveaux par classe, marqueur de désaccord. ComparerUne colonne par classe, absence marquée « — » et non par un vide. FavorisTableau identique à la liste + l’état vide. JetonsLe banc d’essai : surfaces, écoles, échelle, états. tokens.cssLe fichier de jetons lui-même — à porter dans theme.css / tokens.ts.

À donner à Claude Code avec le document : « voici le système, voici cinq écrans qui l’appliquent — porte-les sur les routes du dépôt, sans réinventer les valeurs ».
